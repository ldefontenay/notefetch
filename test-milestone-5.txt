NoteFetch milestone 5 test: the Uncategorised folder, Settings and the first sync

About 40 minutes. It checks everything new in milestone 5: the
Uncategorised folder you chose, the Settings window, moving your recordings
to another output folder, signing in and out from Settings, and the
question the very first sync asks.

Sections 1 to 4 run on the same test copy as before. Section 5 uses a new,
empty copy, so that NoteFetch thinks it has never synced. It needs you to
sign in to Plaud in your browser once more, and it downloads a few
recordings into the test-data folder.

Please write your answers after each ANSWER line. Leave any you cannot do
blank, and say so. Save the file when you are done.


SECTION 1: THE UNCATEGORISED FOLDER

1. In File Explorer, go to C:\Users\ldefo\dev\NoteFetch\test-data and press
   Enter on "Start NoteFetch test.cmd". Wait for "Sync finished." Then
   press Alt+G for the Log, and read down a few lines.
   Expected: a line saying "Moved 50 recordings into the Uncategorised
   folder, so the output folder holds only folders." (the number may
   differ a little). This happens only this once.
   Was it there?

ANSWER:
Yes. From the log, it looks like this is the first thing the app did. Very good.
2. Press Alt+C for the list. Arrow to a recording that is not in
   Neuroscience, and listen to the whole row.
   Expected: its Folder column says "Uncategorised". A recording not
   downloaded has nothing in that column, since it is not on disk yet.
   Was it so?

ANSWER:
Yes
3. In File Explorer, go into C:\Users\ldefo\dev\NoteFetch\test-data\output.
   Expected: only two folders, "Neuroscience" and "Uncategorised". Go into
   Uncategorised: it holds the recording folders, each one ending in its
   date and time.
   Does this tell recording folders and category folders apart the way you
   hoped?

ANSWER:
Yes, excellent.
4. Back in NoteFetch, press Alt+E for the Folder box and arrow through it.
   Expected: "All folders", "Uncategorised", "Neuroscience". Choose
   Uncategorised. The list shows only recordings in it, plus those not yet
   downloaded (they will go there).
   Then press Alt+L for the Folder menu and arrow to Rename folder and
   Delete folder.
   Expected: both unavailable, saying "Uncategorised is NoteFetch's own, so
   it cannot be changed". Press Escape twice.
   Was it so, and is that wording clear?

ANSWER:
Yes.

Yes

Yes. Also make sure that "uncategorized" can't go through. Which makes me wonder whether its best to follow UK or American spellings in the app. I'd like your steer on that please.

    Done?

ANSWER:
Yes
12. Press Ctrl+Comma, then Alt+B for Browse. The Windows folder picker
    opens. Choose the "output 2" folder you made, and press Enter on
    "Select Folder".
    Expected: you are back in Settings with focus on Output folder, and
    JAWS reads the new path, ending in "output 2".
    Was it so? How did the folder picker go with JAWS?

ANSWER:
All good, standard dialogues as expected. Note that the list of folders initially displayed was the content of the output folder, i.e. uncategorised and neuroscience. Ideally it should be a level up the tree, i.e. listing the folder containing the output folder.

13. Press Enter for OK.
    Expected: a question: "Move your 51 downloaded recordings to the new
    output folder?", with From and To lines. Press N for No.
    Expected: you are back in Settings, and the output folder is the old
    one again. Press Alt+B and choose "output 2" again, then press Enter,
    and this time Y for Yes.
    Expected: "Moving your recordings to ...output 2", then "Moved 51
    recordings to "...output 2". It is now the output folder."
    What did you hear?

ANSWER:
Exactly as expected. Note: Please make "no" the default option when enter is pressed and have focus land on "no" instead of "yes". More cautious, but could prevent some accidents.
